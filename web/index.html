🥪 Lunch, from a browser

The same C# kitchen as the console demos. Open the browser's dev tools Network tab before you click.

1. Call the gRPC port with plain fetch()

Browsers can't speak raw gRPC: they give JavaScript no control over HTTP/2 frames or trailers.

2. The same service over gRPC-Web

gRPC-Web wraps each call so a browser can send it, using HTTP/1.1 and putting the trailers in the response body. The kitchen translates it with ASP.NET Core middleware, so no Envoy is needed.
